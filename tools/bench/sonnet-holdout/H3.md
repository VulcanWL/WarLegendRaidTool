CAUSE 1: ligne 40 — Quand le module est désactivé, la branche else appelle SetCV(CVAR, db.previous) sans vérifier que previous est non vide. Avec la valeur par défaut "", la CVar est écrasée par une chaîne vide à chaque connexion (Apply est appelée au login/reload). Il ne faut restaurer que si une valeur a été sauvegardée.
CORRECTIF:
```lua
    elseif db.previous ~= "" then
        SetCV(CVAR, db.previous)
        db.previous = ""
    end
```
