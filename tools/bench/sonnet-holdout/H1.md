CAUSE 1: ligne 47 — En champ de bataille, GetAreaSpiritHealerTime() renvoie un nombre secret. `left and left > 0` fait un test booléen (et une comparaison) sur cette valeur secrète, ce qui lève l'erreur. Il faut tester issecretvalue avant toute opération.
CORRECTIF:
```lua
local function SyncFromSpiritHealer()
    if not UnitIsDeadOrGhost("player") or not GetAreaSpiritHealerTime then return end
    local left = GetAreaSpiritHealerTime()
    if issecretvalue and issecretvalue(left) then return end -- valeur secrète : on garde le décompte local
    if left and left > 0 then nextWave = GetTime() + left end
end
```
