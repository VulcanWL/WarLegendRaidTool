CAUSE 1: ligne 59 — `if nextWave <= now` n'avance que d'une seule vague (30 s) par appel. Si la dernière vague synchronisée date de plus de 30 s, nextWave reste dans le passé et `left` est négatif. Il faut une boucle `while` pour rattraper toutes les vagues écoulées.
CORRECTIF:
```lua
while nextWave <= now do nextWave = nextWave + WAVE end -- the waves go on after you are back alive
```
