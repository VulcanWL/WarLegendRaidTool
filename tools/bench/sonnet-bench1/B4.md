# Revue de AutoPromote.lua

## Bug 1 : lignes 80-81 : `box` référencé dans sa propre initialisation (plantage)

```lua
local box = W.Check(UI.rankPanel, "", function() return box.rankName and db.ranks[box.rankName] end,
    function(v) if box.rankName then db.ranks[box.rankName] = v; Check() end end)
```

En Lua, la portée d'un `local` ne commence qu'après l'instruction complète. Dans les deux closures, `box` désigne donc la variable **globale** `box`, qui vaut nil. Dès que `c:Sync()` appelle le getter (ligne 89), ou qu'on clique sur la case, l'addon plante avec "attempt to index global 'box' (a nil value)". Les cases de rangs ne fonctionnent donc jamais.

Correction :

```lua
local box
box = W.Check(UI.rankPanel, "", function() return box.rankName and db.ranks[box.rankName] end,
    function(v) if box.rankName then db.ranks[box.rankName] = v; Check() end end)
```

## Bug 2 : ligne 91 : borne de boucle fausse (comportement faux)

```lua
for i = #ranks, #UI.rankChecks do UI.rankChecks[i]:Hide() end
```

La boucle démarre à `#ranks`. Or la case d'indice `#ranks` vient d'être affichée par la boucle précédente (lignes 77-90). Elle est donc cachée aussitôt, et le dernier rang de la guilde n'est jamais visible ni cochable. Si `#ranks == 0` et `UI.rankChecks` est vide, la boucle commence à 0 et n'a rien à cacher. Il faut commencer à `#ranks + 1`.

Correction :

```lua
for i = #ranks + 1, #UI.rankChecks do UI.rankChecks[i]:Hide() end
```

## Bug 3 : fichier entier : aucune traduction française (violation des règles)

Le fichier appelle `L()` pour onze textes visibles et n'a aucun `W.AddFR({...})`. Les règles exigent que le français soit déclaré dans le même fichier. Sans cela, ces textes restent en anglais pour un client français.

Textes concernés : " promoted to assistant.", "Auto Promote", "Add players (separated by comma or space):", "Add", "Auto-promoted players:", "Guild ranks to promote:", "No guild, or ranks still loading...", "Works when you are raid leader, out of combat."

Correction : ajouter un bloc à la fin du fichier (ou au début, tant que ce n'est pas appelé avant ADDON_LOADED) :

```lua
W.AddFR({
    [" promoted to assistant."] = " promu assistant.",
    ["Auto Promote"] = "Promotion auto",
    ["Add players (separated by comma or space):"] = "Ajouter des joueurs (séparés par une virgule ou un espace) :",
    ["Add"] = "Ajouter",
    ["Auto-promoted players:"] = "Joueurs promus automatiquement :",
    ["Guild ranks to promote:"] = "Rangs de guilde à promouvoir :",
    ["No guild, or ranks still loading..."] = "Pas de guilde, ou rangs en cours de chargement...",
    ["Works when you are raid leader, out of combat."] = "Fonctionne quand vous êtes chef de raid, hors combat.",
})
```
