CAUSE 1: ligne 323 — `v == nil` compare la valeur retournée par GetRaidTargetIndex alors qu'elle peut être secrète ; la comparaison lève l'erreur (et W.Safe(v) ligne 324 risque de comparer aussi). Il faut tester issecretvalue avant toute comparaison et renvoyer nil (marque cachée par le client), comme le dit le commentaire.
CORRECTIF:
```lua
local function MarkOf(unit)
    local v = GetRaidTargetIndex(unit)
    if issecretvalue(v) then return nil end
    if v == nil then return 0 end
    return v
end
```
