CAUSE 1: ligne 81 — pcall réussit mais renvoie un booléen secret dans `visible` ; `ok and visible` fait alors un test booléen sur une valeur secrète, d'où l'erreur. pcall ne protège pas l'usage ultérieur de la valeur. Il faut écarter les valeurs secrètes avant de les tester.
CORRECTIF:
```lua
local ok, visible = pcall(it.IsVisible, it)
if ok and not issecretvalue(visible) and visible then
    shown[#shown + 1] = it
    local okw, w = pcall(it.GetWidth, it)
    if okw and not issecretvalue(w) and type(w) == "number" and w > 0 then size = w end
end
```
CAUSE 2: ligne 84 — `type(w) == "number"` est vrai pour un nombre secret, puis `w > 0` lève la même erreur de comparaison ; d'où la garde issecretvalue(w) ci-dessus.
