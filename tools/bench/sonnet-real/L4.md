CAUSE 1: ligne 106 — UpdatePower fait confiance au `unitID` reçu, or les événements de puissance sont routés vers les cadres par le nom du joueur : avec des homonymes, le nom résout vers un autre joueur (UnitPower("Nom") lit le premier correspondant), donc la barre affiche la mana d'un autre. Le cadre doit lire sa propre unité (token raidN/partyN) ou valider que l'unité de l'événement est bien la sienne.
CORRECTIF:
```lua
function playerButton.Power:UpdatePower(unitID)
    if not unitID and WarLegendPvP.UserButton == playerButton
        and not (playerButton.PlayerDetails and playerButton.PlayerDetails.isFakePlayer) then
        unitID = "player"
    end
    if unitID then
        -- un nom ne désigne pas forcément ce joueur : on ne garde que l'unité qui est bien celle du cadre
        local own = playerButton.unitID  -- token propre du cadre (à adapter au champ réel)
        if own and unitID ~= own and not UnitIsUnit(unitID, own) then unitID = own end
        pcall(self.UpdateMinMaxValues, self, UnitPowerMax(unitID))
        local value = UnitPower(unitID)
        if issecret(value) or value ~= nil then self:SetValue(value) end
    else
        self:UpdateMinMaxValues(1)
        self:SetValue(math_random(0, 100)/100)
    end
end
```
Le vrai correctif est dans le routage des événements : indexer les cadres par token d'unité ou GUID, jamais par nom.
