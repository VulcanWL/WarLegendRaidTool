CAUSE 1: ligne 7 — PLAYER_LOGIN est appelé directement pendant l'exécution du fichier, donc avant ADDON_LOADED (qui n'est envoyé qu'après le chargement de tous les fichiers de l'addon, et donc après le chargement des SavedVariables au moment où le handler les lit). L'initialisation de la base se fait donc avec les valeurs par défaut, puis les options enregistrées sont écrasées ou jamais appliquées. Il faut attendre ADDON_LOADED avant de lancer PLAYER_LOGIN / PLAYER_ENTERING_WORLD.
CORRECTIF:
```lua
if IsLoggedIn() then
    local f = CreateFrame("Frame")
    f:RegisterEvent("ADDON_LOADED")
    f:SetScript("OnEvent", function(self, _, name)
        if name ~= "WarLegendRaidTool_PvP" then return end
        self:UnregisterEvent("ADDON_LOADED")
        self:SetScript("OnEvent", nil)
        WarLegendPvP:PLAYER_LOGIN()
        WarLegendPvP:PLAYER_ENTERING_WORLD()
    end)
end
```
Les deux appels s'exécutent alors une seule fois, après que les variables sauvegardées sont disponibles et fusionnées avec les défauts.
