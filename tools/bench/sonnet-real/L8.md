CAUSE 1: ligne 50-52 — Le nettoyage supprime toute recrue absente de la liste `members` du scan. Si la liste ne contient pas les membres hors ligne (option "afficher les membres hors ligne" décochée) ou est partielle, une recrue déconnectée est jugée "promue ou partie", son entrée est effacée, puis recréée avec la date du jour au scan suivant.
CORRECTIF:
```lua
    local now, at, present = time(), {}, {}
    for _, m in ipairs(members) do
        local k = m.full:lower()
        present[k] = m.rank
        if m.rank == db.trialRank then
            at[k] = true
            if not db.trials[k] then db.trials[k] = now end
        end
    end
    for k in pairs(db.trials) do
        -- supprimer seulement si on VOIT le membre avec un autre rang
        if not at[k] and present[k] then db.trials[k] = nil end
    end
```
CAUSE 2: ligne 45 — `m.full:lower()` dépend de la forme du nom (avec ou sans royaume) ; si elle varie d'un scan à l'autre, la clé ne correspond plus et la date est recréée.
