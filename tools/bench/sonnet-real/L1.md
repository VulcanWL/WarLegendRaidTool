CAUSE 1: ligne 1049 — `Index` est une fonction locale déclarée seulement à la ligne 1055, donc après W.Button. En Lua la portée d'un `local` commence après sa déclaration : dans W.Button, `Index` est résolu comme global, qui vaut nil, d'où l'erreur. Il faut déclarer `Index` avant W.Button.
CORRECTIF:
```lua
-- Search index (/wl search box): avant W.Button
local indexOff = false
local function Index(text, widget)
    local m = W.building
    if not m or indexOff or type(text) ~= "string" or text == "" then return end
    m.index = m.index or {}
    m.index[#m.index + 1] = { text = text, widget = widget }
end

function W.Button(parent, text, w, h, onClick, tip)
    ...
    Index(text, b)
    return b
end
```
