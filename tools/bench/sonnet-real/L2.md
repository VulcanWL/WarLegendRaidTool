CAUSE 1: ligne 71 — `if max and issecret(max)` fait un test booléen (`max and ...`) sur une valeur secrète avant de tester issecret : cela lève une erreur, avalée par SafeCall, donc UpdatePower s'arrête avant SetValue (ligne 108) et la barre reste figée. Il faut tester issecret en premier, sans jamais évaluer la valeur secrète en booléen.
CORRECTIF:
```lua
    function playerButton.Power:UpdateMinMaxValues(max)
        if issecret(max) then
            self:SetMinMaxValues(0, max)
            self.maxValue = nil
            return
        end
        if max and max ~= self.maxValue then
            self:SetMinMaxValues(0, max)
            self.maxValue = max
        end
    end
```
